# ADR 004：検証ルールはAIから独立させる

## 判断

AIには「印字された値をそのまま読む」ことだけを頼み、計算で補完させない。正しさの判定は `src/core/rules.ts` の純粋関数が行う。PDFに文字情報がある場合は、登録番号・請求書番号・金額・請求日がその中に存在するかも照合する（AIが値を作り出していないかの確認）。

## 理由

- AIに計算させると、誤った請求書を「正しく直して」読んでしまい、誤りが消える。
- ルールを決定的にしておけば、AIを使わずに網羅的なテストができる。評価用の誤りを含む請求書6枚は、正解データに対してCIで毎回全件検出を確認している。

## 端数処理

消費税の端数処理は請求書ごと・税率ごとに1回と定められており、切捨て・切上げ・四捨五入のいずれも認められる。そのため税額は「対価×税率の切捨て〜切上げの範囲内」を正とした。
