# ADR 003：AIを呼ばない公開デモ

## 判断

公開デモ（`APP_MODE=demo`）はプロセス内のPGlite（WASM版PostgreSQL）に同じスキーマを適用し、架空の会社・3役割・7枚の請求書を、UIと同じサービス関数を通して投入する。AI抽出は `fixtures/demo-extractions.json` の事前データを返す。

事前データは評価用の正解データから機械的に作る。読み取りにくい画像6枚には「登録番号に自信がない」という申告を付け、inv-29だけは登録番号の末尾2桁を入れ替えて、確認画面が疑わしい値を捉える様子を見せる。これはAIの出力ではなく、画面上も「デモ用の事前データ（AIの出力ではありません）」と表示する。

## 理由

- 作者のAPIキーで誰でも使える公開サービスは、費用と乱用のリスクがある。
- 固定の画面だけでは権限・承認・監査の動きが伝わらない。デモも本番と同じSQLとRLSを通す。

## 制約

- デモのデータはサーバーの再起動で初期化される。サーバーレス環境ではインスタンスごとに別のデータになることがある。
- デモで読み取れるのは同梱のサンプル（ファイルのSHA-256で照合）だけ。
